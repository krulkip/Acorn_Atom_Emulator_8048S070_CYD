ATOM 6502 CYD V061
====================

Baseline
--------
Built directly from the confirmed-working V060 project.

Change in V061
--------------
Adds only the first colour graphics mode exposed by the actual
Atom_FloatingPoint.rom COLOUR command.

After CLEAR 1, COLOUR n clears VDG control bit $20.  The $B000 high
nibble therefore changes from $30 (monochrome Mode 1, 128x64) to $10,
which is the MC6847 64x64 four-colour graphics mode.

Colour Mode 1 layout implemented here:
- VDG high nibble: $10
- Logical resolution: 64x64
- VRAM: $8000-$83FF
- 16 bytes per row
- 4 pixels per byte
- 2 bits per pixel, left-to-right as bits 7:6, 5:4, 3:2, 1:0
- Native display expansion: 4x3 raster pixels per logical pixel,
  yielding the same centred 256x192 active raster as the monochrome modes

V061 palette
------------
V061 implements MC6847 colour set 0 only:
  00 = green
  01 = yellow
  10 = blue
  11 = red

This matches the four values generated by the D-ROM COLOUR command's
$00/$55/$AA/$FF colour-byte table.  Alternate CSS palette handling is
not implemented yet; it will be investigated separately rather than guessed.

Deliberately unchanged
----------------------
- Mode 0 alphanumeric + semigraphics renderer
- Monochrome Mode 1 128x64 renderer
- Monochrome Mode 2 128x96 renderer
- Monochrome Mode 3 128x192 renderer
- Monochrome Mode 4 256x192 renderer
- 6502 core and F-ROM mapping fix
- keyboard matrix, ESC/BREAK and immediate keyboard handling
- 8255/VIA/flyback timing
- TFT_eSPI board selection and setup

Suggested first test
--------------------
CLEAR 1
COLOUR 1
PLOT 13,10,10
COLOUR 2
PLOT 13,20,20
COLOUR 3
PLOT 13,30,30

In colour mode the background colour value 00 is green; the three plotted
points should be yellow, blue and red respectively.
