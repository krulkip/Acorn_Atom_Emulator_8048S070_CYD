Important AtoMMC directory behaviour
------------------------------------
These commands are intentionally different:

    *CAT GAMES05

catalogues GAMES05 but DOES NOT change the current working directory.

To enter that directory, use:

    *CWD GAMES05
    *CAT
    *RUN INVADERSZX

This matches the genuine AtoMMC command semantics.

Why INVADERSZX previously failed
--------------------------------
The 10-character name INVADERSZX is accepted intact. The failure occurred
because the current AtoMMC directory was still '/', so the backend correctly
looked for:

    /ATOM/TAPES/INVADERSZX.atm

instead of:

    /ATOM/TAPES/GAMES05/INVADERSZX.atm

After:

    *CWD GAMES05

the file opens and *RUN works normally.
